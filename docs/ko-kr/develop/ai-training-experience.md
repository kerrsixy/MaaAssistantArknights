# MAA AI 학습 경험 기록

이 문서는 MAA를 학습, 조정, 검증하면서 얻은 재사용 가능한 경험과 결론을 기록합니다. 저장소를 새로 받는 개발자와 작업을 이어받는 AI를 위한 문서입니다. 현재 예시는 통합전략 ｢침몰자의 검은 흐름 수해｣에서 얻었으며, 앞으로 보전파견 등 다른 모드도 같은 구조로 추가합니다.

각 항목에는 날짜, 모드, 클라이언트, 목표, 현상, 증거, 가설과 배제 과정, 변경 사항, 검증 범위, 결론, 다음 작업을 기록합니다. 스크린샷, 원본 로그, Core 평가, 데이터 스냅샷, 외부 URL과 확인 날짜를 남기고 사실과 추측을 분리합니다.

## 예시

### 오래된 모집 템플릿

모집 화면에서 `Recruit.png`가 더 이상 일치하지 않으면 실패 화면과 로그를 저장하고 `tools/maa_core_eval.py`로 템플릿 세대, ROI, 임계값, 배율, 클라이언트 리소스를 분리해서 확인합니다. 새 템플릿은 깨끗한 게임 UI에서 만들고 백업을 남긴 뒤 인식, 선택, 확인, 복귀 전체를 Debug와 실기에서 검증합니다.

### 검색 영역 폭 부족

OCR이 왼쪽 카드만 읽는다면 전체 화면, 이전/새 ROI, 카드 수, OCR 원문, 중복 제거 규칙, 가장자리 사례를 기록합니다. ROI를 넓힌 뒤 오인식, 페이지 이동, 축소, 성능을 다시 확인해야 합니다.

## 현재 흑류 수해 실전 경험

- Bilibili 클라이언트는 연결 전에 `ClientType=Bilibili`를 설정하고 흑류 수해 터미널에서 시작해야 합니다. 데스크톱, 로그인, 이전 결과, 분대 선택 화면은 먼저 기록하고 정리합니다.
- 신규 오퍼레이터 6명, 아바타, `dispatcher` 분기를 동기화했습니다. Horn의 목표 지점 배치는 전투 중 모듈 장착 증거가 필요합니다.
- Unknown 배치 칸은 `BattleHelper`가 격리합니다. Bilibili ｢木本玉米｣에서 중복 클릭 방지는 확인했지만 모든 칸의 유효성을 보장하지는 않습니다.
- ｢无主地｣의 거대 버섯은 임시 고용원이 제거한 뒤 원거리 칸이 됩니다. 전용 작전은 작성했지만 실기 성공 사례는 아직 없습니다.
- 적 구성은 무작위이므로 고정 작전만으로 안정성을 증명할 수 없습니다. 3층 ｢生存习性｣은 의료 부족과 파란 출구 쪽 배치로 3/22에서 실패했고 오른쪽 배치 작전을 검증 중입니다.
- 첫 결말 통과는 `game_pass:true` 최종 결과만 인정합니다.

## 외부 자료 확장

테마 페이지에서 조사 기록, 스테이지 기록, 적 도감, 비정규 적 도감, 장치 페이지, 개별 적 페이지로 따라가며 Wiki 내용을 게임 데이터, 저장소 리소스, 실기 화면과 대조합니다. 적 도감은 이름, 스테이지 코드, ID, 지위, 종족, 공격 방식, 피해 유형, 위치로 검색할 수 있습니다. 모든 결론에 URL과 확인 날짜를 기록합니다.
